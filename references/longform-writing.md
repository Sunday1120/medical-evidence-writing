# 长文与专业说明

先明确文章要回答的问题和读者读完需要理解的内容，再选择章节。不要按收集资料的顺序堆砌，也不要为了满足统一模板加入无关疾病背景。

1. 基于需求和材料形成提纲，列出各部分需要支持的关键表述。
2. 按证据核验参考获取来源，记录表述对应关系；复杂、数据密集或有争议的问题适合使用证据矩阵。
3. 起草时保留稳定来源 ID，数字、结论及建议旁放置对应引用。复合句来源不一致时拆句。
4. 审校逻辑、证据与表达，再按用户格式或默认的首次出现顺序整理引用。
5. 默认交付带引用成稿与参考文献，仅对实际影响使用的证据缺口作说明。

完整证据包可包括证据矩阵、检索记录和结构化来源。清洁版、单独 citation map 及论文下载包按明确需求增加，不把这些文件作为所有长文的固定门槛。

清洁版只能移除版式上不需要的引用标记，不能改变条件、结论和关键风险说明；仍保留配套来源表。

叙述性综述不等于系统综述。用户要求正式系统综述或 Meta 分析时，应说明另需协议、数据库策略、纳排标准、筛选与偏倚评估等方法工作；本 skill 只承担其中的写作与表述核验，不宣称已完成全部研究方法。
