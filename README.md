# 医学循证写作与审校

一个独立的中文 Agent Skill，用于医学科普、患者教育和专业说明材料的写作、改写、翻译及医学准确性审校。

重点是把关键医学表述和实际支持它的来源对应起来：核对人群、适用条件、数据口径与结论强度，区分已核实内容、有限支持和待核验事项。

## 能处理什么

- **短内容**：海报、图片配文、短口播、简短科普；篇幅短也保留必要的核验。
- **长文**：科普文章、叙述性综述、培训与专业说明；按需提供证据表。
- **医学审校**：定位原文问题，给出修改建议、依据和资料缺口。
- **翻译与润色**：保留医学含义、限定条件和引用，不擅自扩大成研究项目。

默认交付任务需要的文案或审校结果与来源。完整证据包、清洁版和论文下载按需提供。

本项目不提供个体诊疗决策、病历自动生成、正式法律合规批准或完整系统综述方法服务。中国药企广告、隐私和药物警戒合规没有作为通用规则内置。

## 安装与环境

采用 [Agent Skills 标准目录结构](https://agentskills.io/specification)。将整个仓库目录作为一个 skill 使用，目录名保持为 `medical-evidence-writing`，根目录包含 `SKILL.md`。下载压缩包后如目录名带 `-main` 等后缀，请先改为该名称，再放入目标工具配置的 skills 目录。

不依赖其他医学 skill、私有仓库或指定 MCP 服务。`agents/openai.yaml` 是可选界面元数据；其他工具是否识别它由该工具决定。

- 核验当前医学信息需要宿主提供浏览/检索能力；离线时可整理资料与待核验草稿，但不宣称核验通过。
- PDF、DOCX、PPTX、表格和图片需要宿主具备对应读取能力；本 skill 的脚本不替代 OCR 或文档解析器。
- 可选辅助脚本需要 Python 3.11+，仅依赖标准库，无须安装 Python 包。
- 当前验证环境为 Windows、Python 3.12。标准结构不等于已在所有宿主完成端到端验证。

## 使用示例

```text
使用 $medical-evidence-writing，根据我给的资料写一篇约 300 字的患者科普。
保留关键适用条件，给出简洁的表述与来源对应，不需要下载论文。
```

```text
使用 $medical-evidence-writing，审核这份材料的医学准确性。
检查正文和备注里的医学结论，保留页码或单元格定位，给出问题、建议改写和依据。
```

```text
使用 $medical-evidence-writing，面向专业读者写一篇叙述性综述。
需要带引用正文、证据矩阵和检索记录；参考文献按首次出现顺序编号。
```

```text
使用 $medical-evidence-writing，只做这段医学材料的忠实翻译。
保留数字和引用，疑似医学错误单列说明，不自行修正原文结论。
```

参见 [合成案例](examples/合成案例.md)，其中没有真实患者资料或可直接采纳的医学建议。

## 目录

```text
SKILL.md                    统一入口与任务选择
references/                 按需加载的证据、写作、审校及来源规则
scripts/                    目录盘点与显式链接下载
agents/openai.yaml          可选界面元数据
examples/                   合成案例
tests/                      脚本回归测试与行为验证场景
```

脚本命令、输入字段及退出码见 [来源结构与脚本说明](references/reference-schema.md)。先读说明，再对用户指定目录运行；不要把真实材料放入仓库。

## 验证与贡献

从仓库根目录运行，无须安装额外测试依赖：

```bash
python -m unittest discover -s tests -v
```

测试使用临时合成文件和模拟下载响应，不访问真实医学数据或外部服务。测试说明与待执行的模型行为验证见 [行为场景](tests/行为场景.md)。脚本通过不代表医学输出已验证；修改写作规则后应检查相关场景中的成稿表现。

改动时优先修复可复现问题，保持证据规则单一来源。新增地区或企业规则必须标明适用范围，不能默认作用于所有任务。提交例子请使用合成或可公开材料，不附患者信息、客户资料或无再分发权限的论文全文。
